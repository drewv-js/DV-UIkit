# @dv-uikit/vue

Vue integration helpers for DV UIkit web components.

## Usage

```ts
import { createApp } from 'vue';
import { DvUikitVuePlugin } from '@dv-uikit/vue';

const app = createApp({});
app.use(DvUikitVuePlugin);
```

This package currently provides web component registration helpers. Component-level Vue wrappers can be added in a follow-up step.
